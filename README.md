## 🚀 Etapas do Projeto

### ✅ Step 1 — Estrutura inicial
Criação do repositório e estrutura base do projeto.

### ✅ Step 2 — HTML Semântico
Estrutura HTML completa com tags semânticas (`header`, `nav`, `main`, `section`, `footer`).

### ✅ Step 3 — CSS e Estilização
Aplicação da paleta de cores, tipografia e estilo geral com border-radius de 6px.

### ✅ Step 4 — Formulário e Tabela
Seção de contato com formulário e tabela de experiência.

### ✅ Step 5 — Responsividade e Organização do CSS
- CSS separado em 5 arquivos distintos (`variables`, `main`, `header`, `footer`, `form`)
- Variáveis CSS para toda a paleta e tokens de design
- Media queries em 3 breakpoints: 1024px, 768px e 480px
- Tabela com `overflow-x: auto` para rolagem horizontal em mobile

### ✅ Step 6 — Interações com JavaScript
- Menu mobile com botão hamburguer (abre/fecha com animação)
- Accordion na seção FAQ com abertura/fechamento suave
- Botão "Voltar ao topo" fixo que aparece após 400px de scroll
- JavaScript movido para arquivo externo (`script.js`)
