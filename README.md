## 🎯 Objetivo do Site

Este projeto tem como objetivo criar uma landing page pessoal para apresentar informações sobre mim, meus projetos, habilidades e formas de contato. O site servirá como um portfólio digital e cartão de visitas online.

### Funcionalidades Planejadas:
- Apresentação pessoal
- Seção sobre mim
- Projetos e trabalhos
- Habilidades e competências
- Formulário de contato
- Links para redes sociais
